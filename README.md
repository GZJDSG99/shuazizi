# 刷子zi

微信小程序工具集合：首页宫格入口，按工具分包扩展。当前可用工具：**掐指一算**（多份清单、预估/实际、备份与分享长图）。

## 结构

- 主包：`pages/home` 宫格首页 + `config/tools.js` 工具注册表
- 分包 `packageQizhi`：掐指一算（清单列表 / 详情 / 编辑 / 分类）
- 无底部 Tab；新工具 = 新分包 + 注册表加一项

## 掐指一算

- 创建多份清单（装修、旅行、婚礼等都可）
- 每份清单独立：自定义分类、条目、备份、分享长图
- 条目字段：项目名、预估、实际、品牌规格、备注；差额自动算
- 备份：导出到剪贴板 / 覆盖导入当前清单 / 导入为新清单
- 数据仅保存在本机；换机请用备份功能
- 旧版「单份装修账本」数据会在首次打开该工具时自动迁成一份名为「装修预算」的清单

### 换机迁移

1. 打开掐指一算 → 某份清单 →「备份」→「导出备份到剪贴板」→ 微信发给新手机  
2. 新手机复制文本后：  
   - 清单列表页 →「从剪贴板导入为新清单」，或  
   - 进入某份清单 →「备份」→「从剪贴板导入到本清单」（会覆盖该份）

## 使用方式

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本仓库根目录（含 `project.config.json`）
3. AppID 可用测试号；正式发布请换成你的小程序 AppID，并在微信公众平台将小程序名称设为「刷子zi」
4. 建议基础库 ≥ 2.25
