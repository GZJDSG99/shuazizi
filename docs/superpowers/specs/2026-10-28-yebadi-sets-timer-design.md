# 耶巴蒂，莱维贝贝~ — 设计规格

**日期：** 2026-10-28  
**状态：** 已确认；实现计划见 `docs/superpowers/plans/2026-10-28-yebadi-sets-timer.md`  
**目标：** 在「刷子zi」工具箱中新增极简健身工具：记录组数 + 组间休息倒计时；健身房单手可完成主流程。

**宿主：** 微信小程序工具集合（主包宫格 + 按工具分包），风格与首页一致（灰白简约、沉浸导航）。

---

## 1. 目标与成功标准

用户在健身房做组间训练时，需要快速记组数并开始休息倒计时。

成功标准：

- 首页出现工具 **「耶巴蒂，莱维贝贝~」**，点进即用
- 一页完成：改动作名、看组数、完成本组、休息倒计时、跳过休息、重置组数
- 休息结束 **仅长震动**（不弹窗、不强制响铃）
- 记住上次动作名与休息秒数；组数离开页面后仍保留，直到手动重置
- 无账号、无云端；数据仅本机

---

## 2. 范围

### 2.1 第一版包含

- 分包单页训练台
- 动作名编辑（本地记忆）
- 组数显示、完成本组（+1）、重置组数（确认）
- 休息：快捷 30 / 60 / 90 / 120 + 自定义秒数；记忆上次时长
- 倒计时进行中可跳过；到 0 触发 `wx.vibrateLong`
- 沉浸式导航：返回首页 + 标题
- 注册进 `config/tools.js`（仅已上线工具展示）

### 2.2 第一版不做

- 重量 / 次数记录
- 多动作编排、训练计划、历史曲线
- 背景音频、锁屏保活、推送通知
- 账号同步、分享战绩

---

## 3. 技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 结构 | 分包 `packageYebadi` | 与掐指一算一致，控制主包体积 |
| 页面 | 单页 `pages/train/train` | 极简主路径，减少跳转 |
| 计时 | 页内 `setInterval` / 时间戳校正 | 实现简单；息屏不保证准时，规格已明示 |
| 震动 | `wx.vibrateLong` | 用户选定安静提醒 |
| 存储 | `wx.setStorageSync`，key `tool_yebadi_v1` | 与其他工具 key 隔离 |

---

## 4. 信息架构与流程

```
首页 tools
  └─ 耶巴蒂，莱维贝贝~
        └─ /packageYebadi/pages/train/train
```

### 4.1 待命态

- 显示动作名、当前组数 N、休息时长选择、主按钮「完成本组」
- 次要：「重置组数」

### 4.2 完成本组

1. `sets := sets + 1` 并立即持久化  
2. 进入休息态，用当前选中的 `restSeconds` 开始倒计时  
3. UI 切换为大号剩余秒数 + 「跳过休息」

### 4.3 休息中

- 每秒更新显示；建议用结束时间戳校正，减少漂移  
- **跳过休息**：清定时器，回待命（组数保持已 +1）  
- 到 0：震动一次，回待命  

### 4.4 编辑与重置

- 点动作名 → 输入框 / `showModal` editable → 保存  
- 重置组数 → 确认后 `sets = 0`  
- 改休息秒数：点快捷档或自定义；写入存储，供下次默认

## 5. 界面要点

- 色调与首页一致：`#F2F3F5` 底、白卡片、`#111827` 字、沉浸导航模糊顶栏  
- 组数与倒计时用大号数字，主按钮触控区足够大（健身房场景）  
- 快捷档为并排芯片；选中态用深色底  
- 第一版图标：可用本地简单图或文字标；有正式图再换 `tools.js` 的 `icon`  
- 工具展示名完整为：**耶巴蒂，莱维贝贝~**（含波浪号）

## 6. 数据模型

Storage key：`tool_yebadi_v1`

```js
{
  version: 1,
  actionName: '当前动作',
  restSeconds: 60,   // 上次选用的休息秒数
  sets: 0,           // 当前组数，手动重置前保留
  updatedAt: number
}
```

约束：

- `restSeconds` 建议范围 5～600；自定义超出则钳制或 toast  
- `sets` ≥ 0；完成本组时 +1  
- 不与掐指一算或其他工具共用 key  

---

## 7. 错误与边界

- 倒计时中再次点「完成本组」：忽略或仅提示「休息中」（推荐忽略主按钮，只显示跳过）  
- 页面 `onHide` / `onUnload`：清 interval，按结束时间戳在 `onShow` 时若已过期则补震动一次（可选增强；第一版至少清 timer，回前台按时间戳刷新剩余，若 ≤0 则结束并震动）  
- 震动 API 失败：静默失败，不阻断回待命  
- 存储读写失败：toast「保存失败」
